这是基于开源网页版制作的非官方离线封装。原作名称和署名保留，不属于官方商店版本。

项目开发方式标注：**纯 AI 项目**。Android 封装、移动端适配、附加功能、测试脚本、文档与发布整理由 AI 根据用户需求和反馈完成；此标注不将原作、上游源码、翻译、音效或第三方库归为 AI 原创。

原始游戏、翻译、音效及第三方库的许可和署名均保留。APK 的 assets/game 中包含可阅读的 JavaScript、HTML 和 CSS 源码，以及 LICENSE.md；本项目同时提供完整源码压缩包，包括 Android Java 源码、网页适配层和构建脚本。

Android 改动：使用应用内 WebView 直接读取 APK 中的静态资源，移除外部脚本和统计，禁用联网入口，固定简体中文并补充缺失翻译，添加触屏布局、玩家中心地图、字号调节、倾斜操控、方向键、本地存档备份和恢复。保留可保存的 1–4 倍游戏计时和冷却调节。1.0.7 固定动态村庄的区块顺序，使用紧凑的双列建筑与仓库数据，增加场景左右滑动和默认关闭的可选作弊模式（物资补给、免冷却和探索保护）。默认游戏规则沿用上游。上游源文件保持原样；网页差异由 scripts/prepare-android-assets.py 与 android/web/ 中的适配层生成，包括移除旧手势脚本的加载、生成版 Button.js 的冷却倍率和 events.js 的状态持续计时适配。

1.0.8 增加可直接阅读的材料需求与不足数量，重新整理村民人数、职业收益和 1／10 人分配控件，将事件和消息弹窗居中，并独立绘制日夜主题勾选框。

1.0.9 将材料操作统一为尺寸稳定的紧凑横排，增加分类折叠，简化村民分工的分割线并扩大加减触区，将背包余量置于装备列表上方并在滚动时保留。配装信息改为行内说明，按钮使用日夜主题反馈，仓库在大字窄屏下自动改为单列。新增正常上限人口和全职业、全蓝图等后期状态的离线触摸及布局回归脚本。

1.0.10 将探索按键改为支持按住和滑动换向的十字布局，修复持键触发事件后松手误点弹窗，放大局部地图并收紧随身物资布局。收获页取消战斗的固定高度，整理物品与数量、单件和整组拾取，独立显示背包余量，长列表保留可见的继续／离开操作。全部拾取与离开分开；背包满时使用行内替换选项，原有容量、拾取和掉落规则保留。

1.0.11 将战斗改为随内容收缩的居中弹窗，集中攻击与治疗，单操作使用整行、多个操作使用双列，小屏多武器区独立滚动并保留可见的血量和治疗。子弹用尽后生成的原始拳击按钮归入攻击区。事件期间隐藏背景方向键，关闭后恢复。原始战斗、冷却、物资消耗及伤害规则保持不变。

1.0.12 增加作弊模式下的“地图全开”，仅揭开并保存当前和已存地图的迷雾，不提前提交地标进度、奖励或设施解锁。新增菜单与地图入口的中文地标图鉴，包含全部地图符号、用途说明、搜索和当前可见数量；普通模式也可查阅，查阅不揭开迷雾。面板打开时阻止键盘游戏输入，保留文本编辑和按钮的正常操作。图鉴内容为本项目编写的简要参考说明。

手机适配交互参考用户提供的 net.type2play.adr 1.0.7 安装包（仅静态研究其本地网页封装、局部地图、字号和左右倾斜方案）。本项目未复制该安装包的源码、图标或其他素材，继续使用上述上游源码与独立编写的适配层。

本项目新增的 Android 封装、构建脚本与适配代码同样按 MPL-2.0 提供。

1.0.13 增加独立主页面与模式选择，采用原作的简洁文字和细线按钮风格。普通模式进入现有游戏并保留存档；Roguelike 仅提供未开放的占位入口，不包含玩法或新存档。主页面只读取主题、字号与是否有进度，不初始化引擎或写入存档。新增游戏菜单返回主页、原生返回键的分层返回、主页许可返回，以及主页文件恢复后进入普通模式的处理。
