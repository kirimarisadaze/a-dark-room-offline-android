本轮对照用户提供的 UI 与 Bug 清单，以本地 1.3.1 为修复基线。清单提供了复现线索，以下结论来自代码核查、独立边界夹具与真实控件回归。

## 专项与范围

`node scripts/test-rogue-issues.mjs`：40 个种子 × 3 种深度 × 2 种生命 × 4 组补给，共 960 次紧急撤离。每次改变声明的地牢夹具位置，覆盖零 / 部分补给、1 生命、伤害结算边界、非负补给、准确扣血、刷新续存和两个普通存档字符串保护。另覆盖真实战斗锁、连续 20 次缺补给撞墙、等待结局、普通墙、据点与深渊保护、满包、空仓、远程补给、库存守恒和无变化整备的完整 JSON 一致性。

浏览器专项点击实际控件，验证撤离取消 / 确认、默认焦点、刷新、四处整备入口、备用物资补充、菜单退出、原生备份入口保留、建造名称、页面元数据及隐藏焦点。320×512 / 22px、360×740、412×915 / 20px、740×360、1440×900 共十组日夜布局，实际断言主题与字号，检查至少 44px 控件、固定底部按钮命中、无横向溢出、缺译、控制台错误 / 警告、外网请求或缺失资源。

既有核心、生存、储物、UI、后期布局、主页、三存档与普通模式最窄屏离线回归分别执行。完整通关的模型规划会在远行中补给、回营治疗与制作药物；UI 规划始终只读状态，推进全部使用真实控件，不注入资源、生命、迷雾或图纸，不使用援助。测试结果保存在 `.local/rogue-tests/`，不将夹具测试描述为真实新局通关。

未连接 Android 真机。本轮未验证真机安装、系统文件选择器或实际 WebView 交互；浏览器模拟与签名 / 资源检查不替代这些验证，也不能视为真人长期平衡评估。
