# Rogue save fixtures

`rogue-v1.json` is a completed seed-42 run generated by the v1.1.0 legal-action regression player. It retains the original square world, three settlements, explored terrain and ship ending to exercise v1 upgrades without rerolling the world.

`rogue-v2.json` is a completed seed-42 run generated by the v1.2.1 legal-action regression player before the v3 changes. It retains the random regional layout, explored terrain, companions and ship ending to exercise migration of both the active party and an abyss snapshot to v3.

Both fixtures contain generated game data only, without personal data or modified resources.
